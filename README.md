# Lernraum

Локальный учебник немецкого для занятий с моделью-преподавателем в Codex. Интерфейс работает в браузере, SQLite хранится на компьютере. Сайт-хостинг, вход через ChatGPT и ключ API не нужны. Модель выбирается в Codex; код приложения не зависит от её имени или провайдера.

## Запуск на Windows

Требуется Node.js 24 или новее.

1. Один раз выполнить `npm ci` в папке проекта.
2. Выполнить `npm run build`.
3. Дважды нажать `Start-Lernraum.cmd`.

Программа откроется по адресу **http://127.0.0.1:4177**. Сервер работает в фоне только на loopback-интерфейсе. Повторный запуск открывает существующий экземпляр. Если сборки ещё нет, запуск создаст её. После обновления исходников снова выполнить `npm run build` и перезапустить приложение.

Для остановки — `Stop-Lernraum.cmd`. Закрытие вкладки не останавливает сервер. В автозагрузку Windows программа не добавляется.

Ручной запуск на любой системе: `npm start`. Остановка — Ctrl+C в том же терминале.

## Преподаватель

Полная переносимая инструкция: **[TEACHER_PROMPT.md](TEACHER_PROMPT.md)**. Форматы заданий, рубрика и формулы: **[TEACHING.md](TEACHING.md)**. Инструкция написана для любой модели с доступом к локальным инструментам; GPT-6.1 Sol можно выбрать в Codex без изменений программы.

Стартовый запрос:

> Работай как мой преподаватель немецкого. Прочитай TEACHER_PROMPT.md и мой прогресс в Lernraum. Если диагностики ещё нет, уточни мою цель и начни короткую диагностику около B1.

### MCP

В папке проекта создать `.codex/config.toml` для локального STDIO-сервера. Эта настройка относится только к проекту; общую конфигурацию Codex менять не нужно:

```toml
[mcp_servers.lernraum-local]
command = 'C:\Program Files\nodejs\node.exe'
args = ['--experimental-strip-types', 'C:\ABSOLUTE\PATH\lernraum\local\mcp.ts']
cwd = 'C:\ABSOLUTE\PATH\lernraum'
```

Заменить пути на свои. Локальная конфигурация исключена из Git. Если после добавления инструменты не появились в текущем чате, перезапустить подключение MCP или открыть новый чат с этим проектом. Сервер запускается клиентом и не зависит от открытой вкладки Lernraum. [Официальная документация подключения MCP](https://learn.chatgpt.com/docs/extend/mcp?surface=cli).

Доступно пять инструментов:

- `get_teacher_instructions` — инструкция преподавателю и контракт данных.
- `get_learning_progress` — результаты, ошибки, словарь, ожидающие тексты и маршрут.
- `create_lesson` — новое неизменяемое занятие.
- `review_writing` — обоснованный разбор письменного ответа.
- `set_learning_roadmap` — персональный маршрут.

### CLI без настройки MCP

Из папки проекта:

```text
node --experimental-strip-types local/teacher.ts get_learning_progress
node --experimental-strip-types local/teacher.ts list
node --experimental-strip-types local/teacher.ts create_lesson .agent-work/lesson.json
node --experimental-strip-types local/teacher.ts review_writing .agent-work/review.json
```

Аргументы также принимаются через stdin с `-` вместо имени файла. Все входные данные проходят проверку схемы. CLI и MCP используют одну базу с приложением. Сохранённое занятие появляется в интерфейсе автоматически, обычно не позднее чем через 5 секунд.

## Данные и резервные копии

- `data/lernraum.sqlite` — основная база. Файлы `-wal` и `-shm` рядом с ней — часть работы SQLite; не удаляйте их во время работы приложения.
- `data/backups/` — последовательные дневные резервные копии перед первым изменением существующих данных (дата имени — UTC). Срок хранения не ограничен; автоматического удаления копий нет.
- `data/server.log`, `data/server-error.log` — журнал запуска.
- `.agent-work/` — временные файлы заданий и разборов, создаваемые преподавателем.
- Черновики незавершённых ответов хранятся в localStorage браузера на этом устройстве.

Эти данные исключены из Git. Публичный репозиторий содержит исходники, инструкцию и искусственные тестовые примеры; настоящие ответы пользователя туда не отправляются. Само приложение не обращается к внешней модели. При работе в Codex данные, прочитанные инструментом, становятся частью контекста выбранной модели.

В интерфейсе «Прогресс» или «Преподаватель» можно выгрузить JSON с учебными данными. Это читаемый экспорт, не автоматическое средство восстановления базы. Для переноса приложения остановить сервер и локальный MCP, затем скопировать папку `data` в новую установку. Для восстановления из SQLite-копии сначала сохранить текущую `data` отдельно, остановить все процессы Lernraum, затем заменить основную базу выбранной резервной копией; не смешивать старые WAL-файлы с восстановленной базой.

Для тестов или отдельного профиля можно задать `LERNRAUM_DATA_DIR`. Порт ручного запуска задаётся `LERNRAUM_PORT` (по умолчанию 4177); Windows-ярлыки используют стандартный порт.

## Учебные возможности

- Выбор ответа, пропуски, сборка предложения, исправление ошибки, чтение с контекстным переводом, письмо, активное воспроизведение слов.
- Автопереход после верного ответа, клавиатура, подсказки, черновики.
- Повторения с изменением интервалов по успешности и скорости; слово не становится известным от просмотра перевода.
- Прогресс по дням и внутренние показатели 0–100 по грамматике, словарю, чтению и письму на шкалах A1–C2.
- Подтверждение навыков отделено от количества занятий. Подсказанные ответы и демонстрация не повышают оценку.

Курсы и реальные результаты изначально пусты. Свободное письмо проверяет преподаватель через инструмент, а не скрытая автоматическая модель. Заданий на говорение нет. Говорение и аудирование не оцениваются; внутренние баллы не являются сертификатом CEFR.

## Разработка и проверки

```text
npm run check
npm test
npm run build
npm start
```

`tests/local.test.mjs` создаёт отдельную временную базу, проверяет сохранение, повторную отправку, письмо, резервные копии и MCP. Реальные записи ученика не используются в тестах. Старый hosted-вариант сохранён в истории Git, но не является целевой средой и больше не публикуется.
