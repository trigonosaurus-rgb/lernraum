# Lernraum

Личный учебный кабинет немецкого для работы с преподавателем в ChatGPT / Codex. Next/React через Vinext, Cloudflare Worker, D1, приватный Site и четыре MCP-инструмента преподавателя.

## Запуск
Node 22.13+; `npm run install:ci`, `npm run db:generate`, `npm run build`. Применить сгенерированную миграцию к локальной D1 по инструкции Sites, затем `npm run dev`. В Windows при сломанном npm.cmd вызвать npm-cli.js установленного Node напрямую. Войти в локальном браузере через `/signin-with-chatgpt?return_to=/`. Локальный профиль тестовый; production использует идентичность платформы. Данные привязаны к Site-scoped user ID.

Проверки: `node --experimental-strip-types --test tests/model.test.mjs`; `node node_modules/typescript/bin/tsc --noEmit`; сборка через Sites `build-site.mjs`.

## Возможности
- Пустая настоящая учебная история; шесть демонстрационных форматов без сохранения результатов.
- Семь типов заданий, клавиатура, автопереход, локальные черновики, контекстный перевод, сохранение слов.
- Проверка объективных ответов на сервере, идемпотентная отправка, приватное постоянное хранение, экспорт JSON.
- Свободное письмо ждёт внешнего преподавателя; разбор с четырьмя обоснованными оценками.
- Адаптивные интервалы повторения, история по дням Europe/Berlin, отдельные показатели навыков A1–C2.
- MCP: get_learning_progress, create_lesson, review_writing, set_learning_roadmap.

Методика, ограничения и протокол автора заданий: TEACHING.md. Встроенного автоматического вызова языковой модели нет. Слова и занятия не появляются без добавления пользователем или преподавателем. Нет оценивания говорения/аудирования и официальной сертификации CEFR. Результаты локальной QA не мигрируют в production.
